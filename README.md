# Toán Chuyên Lớp 4

Lộ trình ôn toán nâng cao lớp 4 để thi vào trường chuyên: 14 chuyên đề, chia 4 giai đoạn.

Mỗi chuyên đề gồm:
- **Cần nhớ:** công thức, mẹo giải
- **Bài mẫu:** 2–3 bài, lời giải từng bước (bấm để xem)
- **Video bài giảng:** link tới bài giảng tương ứng trên [MathX](https://mathx.vn) (cần đăng nhập)

Mở file `index.html` bằng trình duyệt để dùng. Ô "Đã học xong" lưu tiến độ ngay trên trình duyệt đó.
